# Public syringe instance annotation pilot

This local export contains **29 positive photographs, 29 syringe boxes and 13 visually empty photographs**. The positives span 22 conservative contributor or event groups. One box is an original Open Images annotation and 28 were drawn during the full-scene visual review. Each retained positive contains one visible syringe. The reviewed pilot covers 29 of the target 500 positives, leaving 471. A second human review has yet to take place.

## What the review saw

- The retained Open Images example is a graduated, clear feeding syringe with one box covering the visible barrel, tip and extended plunger. The supplied raster agrees with the box despite an empty publisher rotation field. Flickr currently displays CC BY 2.0 on the photo page. The Open Images annotations are CC BY 4.0. [Flickr original](https://www.flickr.com/photos/15463989@N04/4121265834) · [Open Images licensing](https://storage.googleapis.com/openimages/web/factsfigures_v7.html#licenses)
- The Open Images box on a blood-collection scene covers the visible evacuated tube and its holder. The review found no distinct syringe. Another proposed syringe occurs in an edited Flickr import that credits an unspecified original from Wikimedia Commons. Both were excluded from the export. [Blood-collection photo](https://www.flickr.com/photos/prefeituradeolinda/3992928172) · [Edited Flickr upload](https://www.flickr.com/photos/neuerung/3756149417)
- Open Images labels the crossing syringes on white fabric with a single group box. In another crowded bin, the two labels comprise a group box and an individual box despite additional visible bodies and loose plungers. Both Flickr files display CC BY 2.0. Their publisher geometry remains outside the instance export. [Overlapping syringes](https://www.flickr.com/photos/nathanf/2196763120) · [Crowded bin](https://www.flickr.com/photos/alanna/12663143813)
- LabPics supplies an individual vessel mask per instance ID under `Data.json` and `Vessels/`. One frame of a fan of transparent syringes has eight publisher masks. A second crossing scene has seven and a stack has five. Some visible center barrels or fragments remain unaccounted for or ambiguous at review scale. The archived source notes identify 38 Instagram and 21 YouTube screenshots. The dataset’s MIT declaration does not identify what rights were granted for those individual photographs. - The local review has readily at-hand examples of clear barrels, thin needles, truncation, gloves and visible intranasal applicators. It keeps CDC portraits from the same demonstration together and merges event-level aliases among the military photographs. One packaged syringe was retained from two views. The review kept both capped and exposed-needle views of the same influenza syringe within a single group. ## Other sources and exclusions

Universe declares CC BY 4.0 on Angels, Tals and CS5800. The read-only connector returned 2,514 entries for Angels v1, with resizes, crops, rotations and other augmentation. It returned 1,393 entries for Tals v7 with 640 × 640 stretches and no listed export augmentation. Earlier review found closely repeated equipment views. CS5800 v1 reports 1,050 export entries from a 386-photo project listing, with flips, brightness and rotation in the export. These entry counts cannot establish distinct original photographs. Direct Universe HTTP access returned 403 for the Angels version page. The connected export method can generate a cloud export. No export or fork was initiated. [Universe version pages](https://universe.roboflow.com/use-cases/syringe-detection) · [Earlier local catalog review](public_bulk_syringe_collection.md)

The public Wardy Hazard release supplies YOLO labels and discloses incomplete documentation of image rights. The medical-waste YOLO repository reports 591 syringe instances, but its public repository tree did not contain the training box files or license. EgoSurgery-Tool requires an access request and lists academic noncommercial terms. SID-RAS still has no file listing from the earlier Mendeley public API check. These sources provide no positive images for this export. [Wardy data card](https://huggingface.co/datasets/chocochip119/hazard#source-and-license) · [Medical-waste YOLO repository](https://github.com/manjunathsept11/Medical-Waste-Object-Detection-Using-YOLO) · [EgoSurgery terms](https://github.com/Fujiry0/EgoSurgery#license) · [SID-RAS file API](https://data.mendeley.com/public-api/datasets/cyghvmjrt3/files?folder_id=root&version=1)

Prior MedBin, syringe-test, syringe2 and syringe-detection projects, the related Michaels bench project, Mendeley Dental and simulated phlebotomy were excluded as whole source families. The screen compared established public IDs, normalized source URLs, author names, original and derived SHA-256 values, and rotations/reflections of candidate dHashes within Hamming distance four. The Fil Rouge screen used the recorded inventories. The concurrent crowd-reference manifest excluded two same-photographer Commons images, and the review kept one further crowd acquisition event out of this export. The filters cannot establish independence for unrecorded aliases, strong crops or substantially changed viewpoints. [Existing whole-project exclusions](../../scripts/experiments/public_data/public_catalog_exposure_audit.py) · [Crowd-reference manifest](../../artifacts/detection_hillclimb/crowd_next_reference_manifest.json)

The Wikimedia and CDC rows reuse the file-specific attribution and rights metadata preserved with the existing source receipts. The exporter carries that provenance and did no image redistribution. Type-specific values such as printed volume or liquid contents were outside this review. The small positive set primarily measures potential training-data coverage for single-syringe stills. [Commons reuse guidance](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia) · [CDC PHIL terms](https://wwwn.cdc.gov/phil/faq.aspx)

## Reproduce locally

With the recorded inputs present, rerun the three publication commands to validate review-to-image bindings and rebuild the manifests.

~~~sh
.venv/bin/python -m scripts.experiments.public_data.instance_source_audit publish
.venv/bin/python -m scripts.experiments.public_data.instance_source_supplement publish
.venv/bin/python -m scripts.experiments.public_data.instance_source_export
~~~

The optional `prepare` commands recreate the discovery queue and LabPics audit using the current local protection inputs. Run `check-flickr` to repeat the live source-license requests. A changed discovery queue invalidates the current review binding until each retained row is reconciled. The LabPics archive is under `data/instance-source-review/inputs/`. Its MD5 must match the depositor record.
